V4 변경 사항

수정 파일:
- js/forecast.js

변경 내용:
1. 참고 자료 제목의 HTML 엔티티를 복원합니다. 예: &quot; -> "
2. 중복 공백과 불필요한 구분 기호(|, ·, • 등)를 정리합니다.
3. 지나치게 긴 제목은 96자에서 말줄임표로 줄입니다.
4. URL이 같은 참고 자료는 한 번만 표시합니다.
5. 참고 자료는 화면에 최대 6개까지만 표시합니다.
6. 제목이 사실상 비어 있거나 깨진 경우 해당 자료의 도메인을 대체 제목으로 사용합니다.

기존 유지 사항:
- 영향 문구 자체는 유지하고, "영향도:" 접두어만 제거합니다.
- 방향은 (+), (-), (±), (?) 부호와 설명 문구를 함께 표시합니다.
- 참고 자료의 게시일·활용 이유 반복 문구는 표시하지 않습니다.
- 백엔드 검색 방식과 자료 품질 관련 로직은 변경하지 않았습니다.
