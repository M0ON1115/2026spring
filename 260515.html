벡터와 행렬 상호작용 학습

숫자 배열 · 차원 · 방향 · 길이 · 유사도 · 변환 · 실제 예시

1. 기본

스칼라 Scalar

3
  • 숫자 하나
  • 크기
  • 배율
  • 점수 하나

벡터 Vector

[3, 4]
  • 숫자 한 줄
  • 성분들의 묶음
  • 방향 + 길이
  • 공간 속 점

행렬 Matrix

[1 2]
[3 4]
  • 숫자의 직사각형 배열
  • 행 row
  • 열 column
  • 벡터 변환

관계

  • 스칼라 → 숫자 하나
  • 벡터 → 숫자 여러 개를 한 줄로 배열
  • 행렬 → 여러 벡터를 쌓은 형태
  • 데이터 → 벡터
  • 벡터 → 행렬을 통해 변환

2. 행렬

행렬 크기 선택

선택 영역 판정

생성된 행렬

클릭 / 드래그 선택

  • 1×1 선택 = 스칼라
  • 1×n 선택 = 행벡터
  • n×1 선택 = 열벡터
  • m×n 선택 = 행렬

3. 예시

직접 확인하는 예시

  • 데이터를 벡터로 바꾸면 비교 가능
  • 비슷한 방향은 비슷한 성질을 나타냄
  • 행렬 변환은 공간 배치를 바꿈
  • 압축은 정보를 줄이지만 일부를 잃을 수 있음

4. 데이터를 벡터로 보기

샘플 데이터

벡터 막대 표시

  • 각 막대 = 하나의 성분
  • 막대 높이 = 성분값의 크기
  • 성분 개수 = 차원

5. 2D 벡터

샘플

직접 입력

  • 벡터 = 원점에서 출발하는 화살표
  • x 성분 변화 → 좌우 이동
  • y 성분 변화 → 상하 이동
  • 성분값이 커질수록 길이 증가

6. 3D 벡터

샘플

직접 입력

  • 캔버스 위에서 마우스 드래그 → 회전
  • 휠 → 확대/축소
  • 검은 화살표 = 현재 3D 벡터
  • 점선 그림자 = xy 평면 투영

7. 벡터 연산

연산 선택

샘플

[a,b] + [c,d] = [a+c, b+d]
k[a,b] = [ka, kb]

8. 내적과 코사인 유사도

샘플

직접 입력

A · B = A₁B₁ + A₂B₂
cosθ = (A · B) / (|A||B|)

9. 행렬 변환

변환 샘플

행렬 A

입력 벡터 x

  • 회색 격자 = 원래 공간
  • 붉은 격자 = 변환된 공간
  • 파란 화살표 = 입력 벡터
  • 빨간 화살표 = 출력 벡터
